# 接种日历 · 儿童疫苗规划

填一个出生日期或预产期，就能看到孩子下一次常规接种的参考日期和当天项目。没有填写资料时，可直接浏览国家免疫规划年龄表和疫苗资料。

## 带着接种证使用

- **看下一次安排**：首页将同一天的项目列在一起。点「登记接种」填写实际日期；已接种但找不到日期时也可先登记。点「往期未登记」核对接种证，错过计划日需由门诊安排补种。
- **比较与更换**：从某剂旁的「换方案」进入，或在「疫苗资料」搜索“五联”“九价”等名称，直接比较对应产品。在确认前可「先存为备选」，原时间线和预算不变。门诊核对后点「门诊已确认，应用方案」，只调整待办。五联方案仍保留 6 周岁百白破；已有相关接种记录时可在对比窗中查看，整套切换受到保护。
- **安排自费项目**：时间线切换为「自费项目」。五价轮状按周龄和相邻剂次间隔提示；EV71 第二剂跟随首剂日期。肺炎球菌结合疫苗的日期仅为婴儿期程序示例，品牌和起种年龄会影响剂数。自费费用取自原门诊公示，仅用于家庭估算。
- **记录当季流感**：在「流感疫苗」选择门诊核对的本季剂数和首剂日期，首次灭活两剂程序的第二剂按首剂后至少 4 周推算。每季分开保存，未录入的接种史由家庭核实。页面用当年 7 月至次年 6 月归档，实际接种时机以当地流行季和门诊安排为准。
- **调整或备份**：展开孩子资料可补充性别（用于核对 HPV 资格）、切换查看日期或「跟随今天」。打印会列出完整计划和已有记录。数据仅在当前浏览器、当前地址保存，换设备或浏览器时用「打印与备份」导出和导入。旧备份保留实际日期、手动排期、原单项流感记录和有记录的示例档案。

## 资料依据

全国常规程序与可计入的相应剂次来自[国家疾控局、国家卫生健康委《国家免疫规划疫苗儿童免疫程序及说明（2026年版）》](https://www.ndcpa.gov.cn/jbkzzx/c100014/common/content/content_2073005020766703616.html)，项目内附同版 PDF。时间线与资料页按同一套剂次生成。特殊健康状态、迟种、已有剂次之间的衔接请带接种证向门诊核对。

流感参考[中国疾控中心 2026–2027 年指南](https://ivdc.chinacdc.cn/cnic/fascc/202609/t20260903_1839790.htm)；自费疫苗分别链接[EV71 技术指南](https://www.chinacdc.cn/jkyj/crb2/bl/grxfxb/jswj_fxb/202409/P020240907592483972395.pdf)、河北疾控的[轮状病毒](https://www.hebeicdc.cn/jkdt/83253.jhtml)、[肺炎球菌](https://www.hebeicdc.cn/jkdt/83252.jhtml)和[水痘程序](https://www.hebeicdc.cn/jkdt/83254.jhtml)。原价格来自双桥区西大街街道社区卫生服务中心。资料页另列旧接种证品名、特定人群和暴露处置条目。界面参考了 [NHS 的分步提问设计](https://service-manual.nhs.uk/design-system/patterns/question-pages)。

## 本地打开与维护

运行 `node serve.mjs`，浏览器打开[本机预览](http://127.0.0.1:8731/)。本项目是静态站点，无安装或构建步骤；也可直接打开 `index.html`。运行 `node --test planner.test.cjs` 验证日期、方案、资料关联与备份兼容。

- `data.js`：常规剂次、来源、资料分类与原门诊价格。
- `replacement.js`：替代方案、涉及剂次与历史保护。
- `planner.js`：按日历月/周计算日期、近期安排、按季流感与备份读取。
- `index.html`、`app.js`、`styles.css`：本地交互和打印视图。
