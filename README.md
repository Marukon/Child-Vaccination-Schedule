# 接种日历 · 儿童疫苗规划

在本机查看儿童常规接种程序、比较同类方案，并记录实际接种。原项目：[Marukon/Child-Vaccination-Schedule](https://github.com/Marukon/Child-Vaccination-Schedule)。

## 本地打开

在本目录运行 `node serve.mjs`，用浏览器打开 [本机预览](http://127.0.0.1:8731/)。项目是静态站点，无安装或构建步骤。需要更换端口时，在命令后加端口号。

## 怎么用

1. 在「孩子资料」填写出生日期和性别；「查看进度的日期」决定完成与待办状态的计算时点。
2. 点击「比较替代方案」，或在时间线点击某一剂旁的「看备选」。方案按疾病分组，列表展示参考剂次和全程费用；展开「对应剂次」可查看切换涉及的项目。
3. 门诊尚未确认时可以保留备选，时间线与自费预算维持当前安排。门诊核对后勾选确认并应用。已应用的方案要切换时，也需先确认新方案。涉及已有接种记录、混用、补种或产品供应的情形，由门诊核对衔接。
4. 「记录 / 改期」可修改参考计划、切换月龄及填写实际日期。实际日期缺失时可以先标完成；标为全程备忘的条目只在产品规定全程完成后勾选。
5. 在「记录与备份」打印、导出或导入。数据只保存在当前浏览器、当前地址下；换浏览器或地址时用备份迁移。备份含接种资料，请妥善保管。旧版备份保留历史记录、自定义日期和备选，原先自动生效的替代关系需重新确认。

## 数据和维护

- 国家免疫规划常规程序与替代条件：[国家疾控局与国家卫生健康委，2026 年版](https://www.ndcpa.gov.cn/jbkzzx/c100014/common/content/content_2073005020766703616.html)。本地附同版 PDF。
- 四价和九价 HPV 的男性适龄范围：[深圳市卫生健康委员会答复](https://www.sz.gov.cn/hdjlpt/detail?pid=3461654&via=pc)。
- 自费方案金额沿用原项目公示估算；不作为报价。当地供应、产品说明书、补种与既往剂次核对以接种门诊为准。
- `data.js` 保存原项目资料与常规剂次；`replacement.js` 管理可比较的方案、互斥及覆盖关系；`planner.js` 计算时间线并兼容备份；`app.js` 管理界面交互。
- 运行 `node --test planner.test.cjs` 检查方案切换、历史保护、日期计算、旧备份迁移及规划接种资格。
